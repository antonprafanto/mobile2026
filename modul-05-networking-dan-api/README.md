# Modul 05: Networking, REST API (Dio), WebSockets, GraphQL & Freezed

Komunikasi backend modern dengan Dio, silent token refresh, serialisasi Freezed, WebSockets realtime, dan GraphQL.

---

## 🎯 Target Kompetensi & Sub-Topik

Setelah menyelesaikan modul ini, Anda akan menguasai:

- [ ] REST API Client dengan Dio: BaseOptions, FormData, CancelToken
- [ ] Dio Interceptors: Logging, Auth Header Injection, Silent Token Refresh (401), Retry Backoff
- [ ] Serialisasi Data & Immutability: json_serializable, build_runner, freezed union states
- [ ] Realtime WebSockets (web_socket_channel): Heartbeat, reconnect, live feed
- [ ] GraphQL Integration: graphql_flutter, queries, mutations, subscriptions
- [ ] Keamanan Jaringan: SSL/TLS Certificate Pinning di Dio

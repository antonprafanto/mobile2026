# Modul 15: CI/CD Otomatis, Fastlane, OTA CodePush, & Rilis Store

Otomatisasi build dan deployment dengan GitHub Actions, Fastlane, Shorebird OTA CodePush, serta publikasi ke Play Store & App Store.

---

## 🎯 Target Kompetensi & Sub-Topik

Setelah menyelesaikan modul ini, Anda akan menguasai:

- [ ] Persiapan Rilis Native: Keystore signing, build.gradle config, Android App Bundle (.aab), iOS Certificates/Profiles
- [ ] Automated Deployment dengan Fastlane: Match certificates, screenshot generation, store deployment
- [ ] GitHub Actions CI/CD Pipeline: Lint, test, build release, auto-upload ke Internal Testing & TestFlight
- [ ] Over-The-Air (OTA) Updates dengan Shorebird CodePush: Patch bug instan tanpa review store
- [ ] Manajemen Google Play Console & App Store Connect: Data Safety, review checklist, rejection handling

---

## 🛠️ Pola Pembelajaran Modul

1. **Analogi Dunia Nyata**: Menjelaskan konsep teknis menggunakan visualisasi sederhana.
2. **Teori & Cara Kerja**: Bedah mendalam arsitektur dan mekanisme di balik layar.
3. **Praktikum Langkah demi Langkah**: Tutorial coding terpandu dengan kode lengkap (*compilable*).
4. **Jebakan Umum (*Common Pitfalls*)**: Kesalahan fatal yang sering dilakukan developer dan solusinya.
5. **Kuis Pemahaman**: Menguji pemahaman konsep kunci.
6. **Tantangan Mandiri & Mini Project**: Proyek praktis untuk mengasah skill secara nyata.

> **Target Output Proyek:**  
> End-to-End Automated CI/CD Pipeline yang menerbitkan build baru ke Store saat git tag di-push.

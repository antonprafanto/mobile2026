# Backend mini: catatan

Folder ini dipakai di [Modul 07](../README.md) bagian 15–16. Bukan proyek Flutter.

## Buka alat ini dulu

| | |
| --- | --- |
| **Buka** | Terminal VS Code (`Ctrl + J`) di folder `backend-catatan` |
| **Perlu** | [Node.js LTS](https://nodejs.org) (v18 atau lebih baru) |
| **Ketik** | perintah di bawah |

```text
npm install
npm start
```

**Kalau berhasil:** terminal menulis `Mendengar di http://localhost:3000`.

Di browser, buka [http://localhost:3000](http://localhost:3000). Harus muncul `{"ok":true,"layanan":"catatan"}`.

Data disimpan **di memori proses**. Tutup terminal → daftar catatan kembali ke contoh. Jangan dipakai untuk data penting.

Langkah tes (Thunder Client / Postman), token, emulator `10.0.2.2`, dan deploy ada di README modul.

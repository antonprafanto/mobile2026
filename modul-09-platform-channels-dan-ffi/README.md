# Modul 09: Native Platform Channels, Pigeon, & Dart FFI

Komunikasi langsung dengan native platform Android (Kotlin) dan iOS (Swift) serta pemanggilan library C/C++ via FFI.

---

## 🎯 Target Kompetensi & Sub-Topik

Setelah menyelesaikan modul ini, Anda akan menguasai:

- [ ] Arsitektur Platform Channels: MethodChannel, EventChannel, BasicMessageChannel
- [ ] Menulis Kode Native: Implementasi Kotlin di Android & Swift di iOS
- [ ] Type-Safe Platform Channels dengan Pigeon: Generator skema native otomatis
- [ ] Dart FFI (Foreign Function Interface): Memanggil library C/C++/Rust langsung dari Dart

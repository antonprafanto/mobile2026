# Lampiran A: Integrasi Payment Gateway (Midtrans, Xendit, Stripe)

Panduan integrasi gerbang pembayaran digital: Snap token, callback URL, webhook verification, dan keamanan transaksi kartu.

---

## 🎯 Target Kompetensi & Sub-Topik

Setelah menyelesaikan modul ini, Anda akan menguasai:

- [ ] Alur Pembayaran Digital (Payment Flow)

- [ ] Keamanan Transaksi: Standar PCI-DSS tanpa menyimpan nomor kartu di aplikasi

# Lampiran E: On-Device AI & Gemini LLM Integration

Menjalankan fitur kecerdasan buatan (AI) lokal di perangkat dan integrasi Google Gemini API di dalam Flutter.

---

## 🎯 Target Kompetensi & Sub-Topik

Setelah menyelesaikan modul ini, Anda akan menguasai:

- [ ] On-Device AI vs Cloud AI untuk Mobile
- [ ] Integrasi Google Gemini API menggunakan Google AI Dart SDK
- [ ] Fitur Multimodal: Analisis Foto Kamera & Teks menggunakan Gemini Vision
- [ ] Chatbot Asisten Pintar & Smart Recommendation di Aplikasi Mobile

# Mobile 2026

Proyek pengembangan aplikasi mobile Flutter dari nol.

## Persiapan & Memulai

1. Pastikan Flutter SDK sudah terpasang:
   ```bash
   flutter --version
   ```
2. Jalankan pemeriksaan perangkat dan dependensi:
   ```bash
   flutter doctor
   ```
3. Mulai kembangkan aplikasi sesuai kebutuhan Anda.

# Fullstack Mobile Developer dengan Flutter™ SDK (2026 Edition)

Repositori pembelajaran dan panduan komprehensif untuk menjadi **Fullstack Mobile Developer** profesional menggunakan **Flutter & Dart**.

Kurikulum ini dirancang mengacu pada standar global **[roadmap.sh/flutter](https://roadmap.sh/flutter)** yang diperluas dengan standar industri: arsitektur enterprise, integrasi backend & database, native platform channels, keamanan aplikasi, pengujian menyeluruh, serta CI/CD & perilisan ke store.

| | **06** | **Data Lokal, Offline-First & Drift/SQLite** | Offline-First Task Manager with Sync Queue |

## 🚀 Prasyarat & Perangkat

1. **Flutter SDK**: Versi 3.x+ (stabil).
2. **IDE**: VS Code atau Android Studio dengan ekstensi Dart & Flutter resmi.
3. **OS**: Windows / macOS / Linux.
4. **Target Platform**: Android (Emulator / HP Fisik) & iOS (Simulator / iPhone via Mac).

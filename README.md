# Fullstack Mobile Developer dengan Flutter™ SDK

Repositori pembelajaran dan panduan komprehensif untuk menjadi **Fullstack Mobile Developer** menggunakan **Flutter & Dart**, disusun mengacu pada standar kurikulum industri dan [roadmap.sh/flutter](https://roadmap.sh/flutter).

## 🗺️ Ringkasan Modul

| No | Modul | Cakupan Utama |
|---|---|---|
| **01** | **Fondasi Dart & Async** | Tipe data, Null Safety, OOP, Future, Stream, async/await |
| **02** | **Flutter UI & Layout** | Widget Tree, Stateless vs Stateful, Responsive UI, Material 3 |
| **03** | **Navigasi & Form** | `go_router`, Deep Linking, Validasi Form, Dialogs |
| **04** | **State Management** | Ephemeral vs App State, Provider, Riverpod, BLoC/Cubit |
| **05** | **REST API & Networking** | Dio, JSON Serializable, Freezed, JWT Authentication |
| **06** | **Data Lokal & Offline** | SharedPreferences, Secure Storage, SQLite (Drift), Hive, Offline-First |
| **07** | **BaaS (Firebase & Supabase)** | Auth, Firestore, Supabase Postgres, Realtime, Cloud Storage |
| **08** | **Fitur Hardware & Device** | Kamera, Geolocator & Google Maps, Biometrik, Permissions |
| **09** | **Clean Architecture** | SOLID, Feature-First, Repository Pattern, Dependency Injection (`get_it`) |
| **10** | **Animasi & UX Polish** | Implicit & Explicit Animations, Hero, Lottie, CustomPainter |
| **11** | **Testing & Performance** | Unit, Widget & Integration Testing, DevTools Profiler |
| **12** | **CI/CD & Rilis Store** | Signing Key, App Bundle (`.aab`), GitHub Actions, Play Console |
| **🏆** | **Capstone Project** | Aplikasi nyata fullstack end-to-end terintegrasi penuh |

## 🚀 Persiapan Perangkat

1. **Flutter SDK**: Versi 3.x+ (stabil).
2. **Editor**: VS Code / Android Studio dengan ekstensi Dart & Flutter.
3. **Emulator / HP Fisik**: Android atau iOS untuk pengujian langsung.

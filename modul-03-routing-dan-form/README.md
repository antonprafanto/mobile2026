# Modul 03: Navigasi Deklaratif (go_router), Deep Linking, & Form System

Membangun sistem navigasi deklaratif dengan go_router, deep linking, route guards, dan validasi form dinamis.

---

## 🎯 Target Kompetensi & Sub-Topik

Setelah menyelesaikan modul ini, Anda akan menguasai:

- [ ] Deklaratif Routing go_router: Route config, path/query params, extra data
- [ ] Nested Navigation: ShellRoute & StatefulShellRoute (Persistent Bottom Nav)
- [ ] Route Guards & Dynamic Redirection (Proteksi Halaman Auth)
- [ ] Deep Linking: Android App Links & iOS Universal Links
- [ ] Sistem Form: TextFormField, TextEditingController, FocusNode
- [ ] Formatters Kustom (Rupiah, HP, KTP) & Feedback UI (SnackBar, Dialog, BottomSheet)

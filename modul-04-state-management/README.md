# Modul 04: Manajemen State Kelas Industri (Provider, Riverpod, & BLoC)

Mengelola data reaktif aplikasi dari skala kecil hingga enterprise dengan Provider, Riverpod 2+, dan BLoC/Cubit.

---

## 🎯 Target Kompetensi & Sub-Topik

Setelah menyelesaikan modul ini, Anda akan menguasai:

- [ ] Teori State: Ephemeral vs App State, Unidirectional Data Flow, Immutability
- [ ] State Bawaan: setState, InheritedWidget, ValueNotifier
- [ ] Provider & ChangeNotifier (Consumer, Selector, context.watch/read)
- [ ] Riverpod 2+: Generator (@riverpod), NotifierProvider, AsyncNotifierProvider, .autoDispose, .family
- [ ] BLoC & Cubit: Event-Driven Architecture, BlocBuilder, BlocListener, BlocConsumer, HydratedBloc
- [ ] Matriks Keputusan: Kapan memilih Provider vs Riverpod vs BLoC di perusahaan

---

## 🛠️ Pola Pembelajaran Modul

1. **Analogi Dunia Nyata**: Menjelaskan konsep teknis menggunakan visualisasi sederhana.
2. **Teori & Cara Kerja**: Bedah mendalam arsitektur dan mekanisme di balik layar.
3. **Praktikum Langkah demi Langkah**: Tutorial coding terpandu dengan kode lengkap (*compilable*).
4. **Jebakan Umum (*Common Pitfalls*)**: Kesalahan fatal yang sering dilakukan developer dan solusinya.
5. **Kuis Pemahaman**: Menguji pemahaman konsep kunci.
6. **Tantangan Mandiri & Mini Project**: Proyek praktis untuk mengasah skill secara nyata.

---

## 📦 Deliverable / Mini Project

> **Target Output Proyek:**  
> E-Commerce Cart, Wishlist, & Multi-Filter State Engine dengan BLoC & Riverpod.

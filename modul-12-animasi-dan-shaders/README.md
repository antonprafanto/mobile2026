# Modul 12: Animasi Lanjutan, Custom Painter, Shaders, & UX Polish

Membangun interaksi visual memukau dengan explicit animations, Hero transitions, CustomPainter Canvas, GLSL Shaders, dan Lottie/Rive.

---

## 🎯 Target Kompetensi & Sub-Topik

Setelah menyelesaikan modul ini, Anda akan menguasai:

- [ ] Implicit Animations: AnimatedContainer, AnimatedOpacity, TweenAnimationBuilder
- [ ] Explicit Animations: AnimationController, CurvedAnimation, TweenSequence, AnimatedBuilder, Staggered Animations
- [ ] Hero Transitions & Custom Page Route Animations
- [ ] Grafis Kustom: CustomPainter & Canvas API (Bezier curves, custom charts, path animation)
- [ ] Fragment Shaders (GLSL) di Flutter Impeller
- [ ] Animasi Vektor Interaktif: Integrasi Lottie dan Rive State Machine

---

5. **Kuis Pemahaman**: Menguji pemahaman konsep kunci.

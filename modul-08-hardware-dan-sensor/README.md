# Modul 08: Integrasi Fitur Hardware, Sensor, & Background Tasks

Mengakses sensor smartphone: kamera, galeri, GPS Google Maps, biometrik sidik jari/FaceID, dan background execution.

---

## 🎯 Target Kompetensi & Sub-Topik

Setelah menyelesaikan modul ini, Anda akan menguasai:

- [ ] Runtime Permission Handling di Android 13/14+ dan iOS
- [ ] Kamera, Galeri & Media: image_picker, camera, flutter_image_compress
- [ ] Geolokasi & Peta: geolocator (GPS, Geofencing) & google_maps_flutter (Markers, Polylines)
- [ ] Keamanan Biometrik: local_auth (Fingerprint & Face ID dengan PIN fallback)
- [ ] Background Tasks: workmanager (Periodic background execution saat app terminate)
- [ ] Local Notifications: flutter_local_notifications (Scheduled alarms & rich notification)

# Modul 14: Keamanan Aplikasi, Kepatuhan (Compliance), & Crash Reporting

Melindungi aplikasi dari serangan, mengamankan rahasia data, kepatuhan UU PDP & GDPR, serta integrasi Sentry & Crashlytics.

---

## 🎯 Target Kompetensi & Sub-Topik

Setelah menyelesaikan modul ini, Anda akan menguasai:

- [ ] Hardening Aplikasi: Code Obfuscation (--obfuscate --split-debug-info), --dart-define-from-file
- [ ] Keamanan Jaringan: SSL Pinning, Anti-Tampering, Root & Jailbreak Detection, Anti-Screen Capture
- [ ] Crash Reporting: Integrasi Sentry & Firebase Crashlytics (Breadcrumbs, Uncaught Errors)
- [ ] Analytics & Telemetry: Firebase Analytics, PostHog, User Funnel tracking
- [ ] Kepatuhan Privasi: Regulasi UU PDP Indonesia & GDPR (Consent flow, Data export, Delete Account)

---

## 🛠️ Pola Pembelajaran Modul

1. **Analogi Dunia Nyata**: Menjelaskan konsep teknis menggunakan visualisasi sederhana.
2. **Teori & Cara Kerja**: Bedah mendalam arsitektur dan mekanisme di balik layar.
3. **Praktikum Langkah demi Langkah**: Tutorial coding terpandu dengan kode lengkap (*compilable*).
4. **Jebakan Umum (*Common Pitfalls*)**: Kesalahan fatal yang sering dilakukan developer dan solusinya.
5. **Kuis Pemahaman**: Menguji pemahaman konsep kunci.
6. **Tantangan Mandiri & Mini Project**: Proyek praktis untuk mengasah skill secara nyata.

---

## 📦 Deliverable / Mini Project

> **Target Output Proyek:**  
> Hardened Secure Banking App Shell dengan Sentry logging, SSL Pinning, dan Anti-Tampering.

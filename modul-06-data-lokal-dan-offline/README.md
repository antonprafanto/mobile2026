# Modul 06: Data Lokal, Offline-First, & Database Relasional (Drift)

Penyimpanan data lokal yang aman, basis data relasional Drift/SQLite, NoSQL Hive/Isar, dan arsitektur Offline-First.

---

## 🎯 Target Kompetensi & Sub-Topik

Setelah menyelesaikan modul ini, Anda akan menguasai:

- [ ] Penyimpanan Preferensi & Kunci: shared_preferences & flutter_secure_storage (Keystore/Keychain)
- [ ] Relational DB dengan Drift & Sqflite: Tables, Foreign Keys, Indexes, Transaksi, Auto-Migrations
- [ ] NoSQL Embedded: Hive & Isar untuk penyimpanan super cepat
- [ ] File System & Image Caching: path_provider, cached_network_image
- [ ] Arsitektur Offline-First: Single Source of Truth (SSOT), Cache Invalidation, Offline Sync Queue

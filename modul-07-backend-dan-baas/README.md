# Modul 07: Sisi Backend untuk Mobile (Dart Frog, Supabase, & Firebase)

Membangun REST API backend dengan Dart Frog, serta integrasi Backend-as-a-Service Firebase & Supabase.

---

## 🎯 Target Kompetensi & Sub-Topik

Setelah menyelesaikan modul ini, Anda akan menguasai:

- [ ] Backend Mobile dengan Dart Frog: REST endpoints, validation, CORS, JWT middleware, PostgreSQL
- [ ] Firebase BaaS: Authentication (Email, Google, Apple), Cloud Firestore NoSQL, Cloud Storage, FCM Push Notifications
- [ ] Supabase BaaS: Relational PostgreSQL, Row Level Security (RLS), Realtime Subscriptions, Edge Functions
- [ ] Perbandingan Arsitektur: Self-Hosted Backend vs BaaS

---

5. **Kuis Pemahaman**: Menguji pemahaman konsep kunci.
